# Сводка отдела и компактные панели, 05.10.2026

## Визуальная структура

Один период и одна команда задают всю правую колонку. По умолчанию новый период — текущий календарный месяц; сохранённый выбор не сбрасывается. Кнопки позволяют перейти к соседнему месяцу.

1. «План–факт»: нормочасы работ, присутствие на объектах, пробег, загрузка с дорогой. Единые колонки «План / Факт / Δ» без отдельных декоративных полос.
2. «Финансы»: работы, дорога и суточные, запчасти; итоги выручки, себестоимости, прибыли и маржи. Затраты по составляющим раскрываются отдельно.
3. «Выездная работа»: километры на нормочас, средний выезд, взвешенная скорость GPS, гарантийность. Подробный график загрузки раскрывается по запросу.

План и маршрут выезда занимают равные по высоте колонки с умеренным соотношением ширины. Задания находятся ниже на всю ширину. На телефоне карточки идут последовательно. Панель диспетчера содержит поиск, фильтры и создание; второстепенные настройки находятся в раскрываемом меню. Убраны повторные разделители и скруглённые inset-подчёркивания выбранных переключателей.

## Источники и смысл чисел

- Выезды относятся к периоду по дате начала и выбранным плановым участникам. Задания на объектах входят через `trip_service_orders`; невыездные задания — по своей дате начала и участникам. Это текущее подтверждённое состояние выбранной группы, не исторический снимок на конец месяца.
- План работ — нормочасовые позиции задания за вычетом перенесённого объёма. Факт — `done_qty` только принятых заданий (`completed`). Связанные с несколькими выездами задания учитываются один раз. Финансово отменённые позиции исключаются.
- Присутствие — проверенные человеко-часы. План выездного присутствия берётся из сохранённого снимка выезда, без подмены текущим редактируемым заданием.
- План загрузки включает завершённые выезды периода. Нормочасы снимка поровну распределяются между плановыми участниками, дорога начисляется каждому. Рабочий фонд рассчитывается по выбранным действующим инженерам, рабочим окнам и календарю. По дням план раскладывается от сохранённого начала.
- Пользователь выбрал загрузку с дорогой. Факт включает проверенное присутствие и измеренные интервалы GPS, распределённые по фактическим дням и согласованному экипажу. При неполном треке, неизвестном пробеге, разных составах экипажа или пересечении со стоянками итоговый процент неизвестен. Для завершённых невыездных заданий без источника elapsed-time полный процент также неизвестен. Частичные измерения доступны на подробном графике с пояснением.
- Километры на нормочас: полный фактический пробег подтверждённых выездов / принятые нормочасы их заданий. Показатель неизвестен, если не все связанные задания приняты либо то же задание связано с выездом за пределами группы. Средний выезд: полный факт-пробег / число подтверждённых выездов.
- Скорость: сумма километров измеренных GPS-участков / сумма их точных длительностей. Достроенные участки и физически неправдоподобные скорости исключаются. Это скорость по измеренным участкам; рядом указано число выездов с измерениями.
- Гарантийность: принятые нормочасы позиций `billable=false` / все принятые нормочасы.
- План финансов — все выезды группы; факт — подтверждённые выезды с проверенным присутствием и экономикой `cost_basis=fact`, `presence_basis=person_hours_v1`. Выручка договорная, не оплата. Компоненты берутся из сохранённых снимков; ручные расхождения с итогами показаны корректировками. Неизвестные компоненты старых снимков не заменяются нулём.
- Все новые чтения постраничные. GPS загружается только для фактических выездов группы. Ошибка GPS не блокирует остальные показатели. Устаревший асинхронный ответ не перезаписывает новый выбранный период.

«—» означает неизвестный или неполный источник; рядом с таблицами указано покрытие. Нулевые измеренные значения сохраняются.

## Проверки и ограничения

Чистые расчёты покрывают дедупликацию связей, переносы, неизвестные значения, принятые работы, состав экипажа, пересечения движения и стоянок, календарные границы Kyiv, снимки завершённых планов, финансовые компоненты и взвешенную скорость.

В Chromium проверяются 360/390/768/1024/1440 px в светлой и тёмной темах, роли, переполнение, размеры touch-целей, раскрытие фильтров и Escape, одинаковая высота карточек выезда, единый период статистики и отсутствие изогнутой тени переключателя. Итоговые результаты выпуска записываются в `CONTINUE-service-dispatch.md`.

Supabase: прочитаны актуальные select-документация и changelog, выполнены read-only `limit 0` запросы новых проекций в QA и production. Схема, RLS, RPC, auth и серверные записи не менялись. Синтетическая визуальная матрица не подтверждает реальное сохранение, offline replay, Safari/Firefox или экранную клавиатуру.
