# Поиск диспетчера и период GPS-журнала · 08.10.2026

На скриншотах заявка использовала поле 420 px, задание — растянутое поле, выезд — сдвинутое вправо. Все три раздела теперь используют одну `.dispatcher-toolbar`: поиск 420 px слева, действия справа; до 1100 px действия переносятся в следующий ряд, на телефоне поиск занимает всю доступную ширину. Общая обёртка поисковых полей устраняет старые различные правила flex/grid. Положение, ширина и высота проверяются сравнением bounding boxes между страницами.

GPS-журнал в этой же области шапки показывает начало/конец периода и ← / Этот месяц / → через существующий компонент сводки `rangeBar`/`wireRangeBar`. Начальное значение — текущий календарный месяц. Отдельное состояние `dl_range_journal` сохраняет выбор и не меняет сводку. Период действует на очередь, архив и списания, включая инженерский доступ к собственным списаниям. При смене периода сбрасываются выбранные участки объединения и предпросмотр.

Серверная фильтрация выполняется до пагинации: `last_ts >= начало` и `started_at < полночь следующего дня после конца`. Таким образом, включаются поездки, пересекающие период, включая начавшиеся раньше; весь исходный трек остаётся доступным для просмотра. Границы рассчитываются для `Europe/Kyiv`, независимо от часового пояса устройства, и учитывают дни по 23/25 часов. SQL read-only production для октября подтвердил UTC-границы 30.09 21:00 → 31.10 22:00 и 7 записей из 31. Данные/схема/RLS/RPC не менялись.
