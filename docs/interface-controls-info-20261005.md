# Переключатели и информационные подсказки — 05.10.2026

Запрос: согласовать стиль переключателей, включая «Таблицы / Диаграммы», и убрать постоянные объяснения под существующие информационные кружочки.

Общая CSS-семья охватывает .seg, .summary-view-switch и .notice-tabs: фон группы, рамка, внутренний отступ, геометрия 8 px, Sans, обычный регистр, нейтральное контрастное выделение. Размер нажатия — минимум 40 px, на сенсорном экране 44 px. Режимы карты, график/статистика, диаграммы/таблицы, все/непрочитанные, корзина, применимость работ и тема используют эти же правила. Навигационные вкладки карточек и разделов сохраняют свою структуру. Выбранное состояние не рисует inset-подчёркивания.

Пояснения в сводке, графиках, полях заявки и выезда, проверке присутствия, заданиях, ответственности, справочнике материалов, настройках автопарка/тарифов, диалогах правки, переноса, push и подключения доступны через существующую .q/.qm/.qbody. Числа, полнота источников, предупреждения о неполных данных, ограничения роли, статусы, ошибки, история и пользовательские комментарии сохраняются на экране. Источники данных, формулы, права и сохранение не меняются.

src/info-hints.js — единое экранирование текста и делегированный обработчик, включая динамические карточки. Открывается одна подсказка. aria-expanded отражает состояние; aria-controls связывает окно с кнопкой. При поддержке Popover API окно использует верхний слой браузера, как существующий выбор инженеров, чтобы контейнер графика не обрезал его на телефоне. Окно ограничено текущим viewport, длинный текст прокручивается, позиция обновляется при прокрутке/resize. Escape закрывает сначала подсказку и возвращает фокус, не закрывая одновременно исходный диалог. Нажатие на текст внутри label не активирует поле/кнопку повторно. Информационный кружочек в заголовке настроек не сворачивает карточку.

Проверки: lint, 581 тест UTC и America/Los_Angeles, production build/smoke. Полная Chromium-матрица отдельно проверяет контраст выбранных переключателей >=4.5:1, единые цвета/геометрию, отсутствие crescent shadow, открытие/границы подсказок, сохранение окна при клике по тексту и Escape/focus. Стенд синтетический, production API блокируются; он не подтверждает Safari/Firefox или реальную авторизованную сессию. При визуальном сравнении выбранных цветов проверка ожидает завершения перехода, вместо снимка промежуточного кадра.
